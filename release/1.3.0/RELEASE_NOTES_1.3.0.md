# DuoBar 1.3.0

DuoBar 1.3.0 expands the native menu-bar experience for MacBooks while retaining DuoBar's macOS 13+ and Universal 2 support.

## What's New

- Adaptive Ring is now available on eligible MacBooks while connected to external power.
- MacBooks return to the Battery Ring immediately when unplugged.
- Adaptive Ring remains Neutral when there is no meaningful performance activity and surfaces sustained CPU, memory, or thermal pressure when appropriate.
- DuoBar now offers clear Small, Default, and Large menu-bar icon-size presets, while preserving precise icon-size control.
- The installer disk image presents DuoBar.app alongside an Applications shortcut.
- If launched directly from the disk image, DuoBar explains how to install it before ejecting the image.

## Distribution

- macOS 13 or later
- Apple Silicon and Intel
- Universal 2
- Developer ID signed and Apple notarized
