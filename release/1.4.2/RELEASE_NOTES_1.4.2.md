DuoBar 1.4.2

### What changed
- Privileged helper: Low Power Mode, Ethernet on/off, and a charge limit slider (20–100%) now work from DuoBar. Install it once from Settings — it asks for your admin password.
- Language: Français is now supported (thanks to Daniel Montoya on GitHub for the translation).
- Settings → General → Liquid Glass: turn it off to bring back the classic pre-1.4.0 popover look.

### Installation
1. Download DuoBar-1.4.2.dmg.
2. Open it and drag DuoBar to Applications.
3. Open DuoBar once from Applications.

Build 11. Artifact size and SHA-256 are published with the GitHub Release.
