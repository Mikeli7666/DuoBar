DuoBar 1.4.1

### What changed
- Desktop Widget: DuoBar now lives on your desktop — the same 3-in-1 glyph (battery ring, network centre, volume dots), draggable anywhere, in 3 sizes. Turn it on in Settings.
- Language: follow your system language or pick your own — English, 简体中文, 繁體中文, Русский, Українська, ไทย.
- Popover: on macOS 26 the glass now matches the native Control Center look, and the popover opens and closes instantly.
- Settings: the Settings window can now be resized and minimized.
- Option-click the network row in the popover to jump straight to Network settings.
- Fix: the battery percentage no longer breaks at the Extra Large icon size (thanks to @lnobre on Threads for the report).

### Installation
1. Download DuoBar-1.4.1.dmg.
2. Open it and drag DuoBar to Applications.
3. Open DuoBar once from Applications.

Build 10. Artifact size and SHA-256 are published with the GitHub Release.
