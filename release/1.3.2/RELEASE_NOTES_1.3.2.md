# DuoBar 1.3.2

DuoBar 1.3.2 refines the status glyph with a new charging animation, an optional battery percentage and a larger icon size, adds audio input switching, and adds Thai.

## What's New

### Charging

- The ring now knocks out around the charging bolt, so the bolt has a clean outline instead of crossing the ring.
- When the battery is full and still plugged in, the bolt dims.

### Status glyph

- New Battery Percentage option shows the battery number on the menu bar icon.
- New Extra Large (120%) menu bar icon size, alongside Default and Large.
- New Ethernet icon: `< ••• >`.

### Audio input

- The popover now has an Audio Input row. Pick the input device from a menu, including an iPhone microphone.
- Selecting an input device does not record audio.

### Localization

- Thai is now available.
- Full localization for English, Simplified Chinese, Traditional Chinese, Russian, Ukrainian and Thai, including the new Extra Large and Battery Percentage settings.

## Compatibility

- macOS 13 or later
- Apple Silicon and Intel
- Universal 2 release target
- Public macOS APIs only

Build 8. Artifact size and SHA-256 are published with the GitHub Release.
