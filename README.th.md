## ไอคอนเดียว สามสถานะแบบเรียลไทม์

DuoBar นำแนวคิด Duo แบบ iPhone ที่รวมสามสถานะไว้ในไอคอนเดียวมาปรับใช้กับแถบเมนูของ Mac ไอคอนขนาดกะทัดรัดหนึ่งชิ้นแสดงข้อมูลระบบที่ปกติกระจายอยู่ตามไอคอนหลายตัว:

- **ส่วนโค้งด้านนอก** → Battery Ring แบบเรียลไทม์บน MacBook หรือ Adaptive Ring บน Mac เดสก์ท็อป
- **ตรงกลาง** → เครือข่ายที่ใช้งานอยู่: Wi-Fi, Ethernet หรือสถานะออฟไลน์/สำรอง
- **จุดสี่จุดด้านล่าง** → ระดับเสียงเอาต์พุตแบบเรียลไทม์

สถานะปกติจะแสดงเป็นสีเดียวกลมกลืนกับรูปแบบของระบบ เมื่อ AirPods หรืออุปกรณ์เสียงบลูทูธอื่นที่รองรับเชื่อมต่อ จุดกึ่งกลางจะเปลี่ยนจากเครือข่าย → AirPods/หูฟัง → เครือข่ายในช่วงสั้น ๆ การตัดการเชื่อมต่อจะไม่มีแอนิเมชัน

## Adaptive Ring และ Battery Ring

บน MacBook วงแหวนด้านนอก (Battery Ring) จะแสดงระดับแบตเตอรี่แบบเรียลไทม์ สัญลักษณ์สายฟ้าขณะชาร์จแบบเคลื่อนไหว และการเข้ารหัสสีแบตเตอรี่แบบเลือกได้สำหรับสถานะชาร์จ, โหมดประหยัดพลังงาน และแบตเตอรี่ใกล้หมด บน Mac เดสก์ท็อป Adaptive Ring จะแสดงความสว่างของจอเมื่อระบบเปิดเผยข้อมูลนั้นได้ และจะแสดงภาระของ CPU, หน่วยความจำ หรืออุณหภูมิที่สะสมต่อเนื่องโดยอัตโนมัติเมื่อจำเป็นต้องได้รับความสนใจ ทุกอย่างทำงานอัตโนมัติ ไม่มีตัวเลือกเมตริกให้เลือกด้วยตนเอง

## ฟีเจอร์

- Battery Ring แสดงระดับแบตเตอรี่แบบเรียลไทม์ สัญลักษณ์สายฟ้าขณะชาร์จ สถานะแบตเตอรี่ใกล้หมด และการเข้ารหัสสีแบตเตอรี่แบบเลือกได้
- Adaptive Ring สำหรับ Mac เดสก์ท็อป: อิงจากความสว่างของจอ พร้อมรับรู้ภาระของ CPU, หน่วยความจำ และอุณหภูมิโดยอัตโนมัติ
- ภาษาภาพแบบ Duo ที่ปรับปรุงใหม่ให้เข้ากับระบบมากขึ้น ไอคอน Wi-Fi แบบโค้งมน, Battery Ring, ไอคอนระดับเสียง และการแสดงผลขณะชาร์จ
- สถานะเครือข่าย Wi-Fi, Ethernet และออฟไลน์แบบอัตโนมัติ
- แสดงชื่อเครือข่าย Wi-Fi และควบคุมการเปิด/ปิด Wi-Fi ผ่าน API สาธารณะ
- พฤติกรรม Open on Hover (เปิดหน้าต่างเมื่อวางเมาส์ชี้) แบบเลือกได้
- ไอคอนระดับเสียงแบบสี่จุดที่อัปเดตแบบเรียลไทม์
- แถบเลื่อนระดับเสียงแบบกะทัดรัด ปิด/เปิดเสียงผ่าน Core Audio สาธารณะ และสลับอุปกรณ์เอาต์พุตในกรณีที่รองรับ
- การแสดงการเชื่อมต่อ AirPods/หูฟังชั่วคราว
- ปรับขนาดไอคอนบนแถบเมนูได้
- รองรับภาษาอังกฤษ รัสเซีย ยูเครน จีนตัวย่อ จีนตัวเต็ม และไทย
- หน้าต่างป๊อปอัปที่กะทัดรัด: Network และ Battery เปิดการตั้งค่าระบบได้โดยตรง, ปุ่มเปิด/ปิด Wi-Fi, ระดับเสียง, การเลือกเอาต์พุตเสียง, การตั้งค่า และปุ่มออกจากแอป
- รองรับทั้งโหมดสว่างและโหมดมืด
- เปิดแอปอัตโนมัติเมื่อเข้าสู่ระบบ
- Universal 2: รองรับทั้ง Apple Silicon และ Intel บน macOS 13+
- พัฒนาด้วย Swift, SwiftUI และ AppKit แบบเนทีฟ
- ไม่มีไอคอนบน Dock

## สิทธิ์การเข้าถึง

- **ตำแหน่งที่ตั้ง:** macOS อาจต้องขออนุญาตก่อนที่ CoreWLAN จะสามารถแสดงชื่อเครือข่าย Wi-Fi ปัจจุบันได้ การปฏิเสธสิทธิ์นี้จะไม่ทำให้การเชื่อมต่อ, อินเทอร์เฟซ หรือสถานะสัญญาณพื้นฐานเสียหาย เพียงแต่ SSID อาจไม่ปรากฏเท่านั้น DuoBar จะขอสิทธิ์เข้าถึง SSID เฉพาะเมื่อมีประโยชน์ต่ออินเทอร์เฟซ
- **บลูทูธ:** DuoBar สังเกตการณ์ตัวควบคุมบลูทูธผ่าน API สาธารณะ ขณะที่ Core Audio เป็นแหล่งข้อมูลหลักสำหรับอุปกรณ์เสียงบลูทูธ แอปนี้ไม่ได้จัดการหรือจับคู่อุปกรณ์ใด ๆ

## พฤติกรรมของเอาต์พุตเสียง

การควบคุมระดับเสียงจะใช้งานได้เฉพาะเมื่อเอาต์พุต Core Audio ที่ใช้งานอยู่เปิดเผยคุณสมบัติระดับเสียงสาธารณะที่ปรับได้ทางซอฟต์แวร์เท่านั้น อุปกรณ์ HDMI, AirPlay, USB และเอาต์พุตภายนอกอื่น ๆ อาจแสดงข้อความ **ควบคุมโดยอุปกรณ์** แทน

การจำแนกประเภท AirPods และอุปกรณ์เสียงบลูทูธใช้เมทาดาทาของระบบสาธารณะแบบ best-effort DuoBar ไม่ได้อ้างว่าตรวจจับรุ่นของ AirPods ได้อย่างแม่นยำ

## ความเป็นส่วนตัว

- ประมวลผลสถานะระบบภายในเครื่องเท่านั้น
- ไม่มีการเก็บข้อมูลวิเคราะห์หรือติดตามพฤติกรรม
- ไม่มีเซิร์ฟเวอร์หลังบ้านหรือระบบเทเลเมทรี
- ไม่มีการอัปโหลดสถานะระบบ
- ไม่มีการเชื่อมต่อเครือข่ายที่ไม่เกี่ยวข้อง

## ข้อจำกัดที่ทราบอยู่

- ชื่อเครือข่าย Wi-Fi อาจไม่แสดงหากไม่ได้ให้สิทธิ์ตำแหน่งที่ตั้ง หรือ macOS ไม่เปิดเผยข้อมูลนี้
- ความแรงของสัญญาณ Wi-Fi ใช้ข้อมูล RSSI ที่มีการเผยแพร่และช่วงสัญญาณแบบกว้าง ไม่ได้จำลองอัลกอริทึมไอคอนส่วนตัวของ Apple
- อุปกรณ์เสียงบางชนิดมีระดับเสียงที่คงที่หรือควบคุมจากภายนอกเท่านั้น
- DuoBar ไม่สามารถเชื่อมต่อเครือข่าย Wi-Fi หรือจับคู่อุปกรณ์บลูทูธได้
- การตรวจจับอุปกรณ์เสียงบลูทูธและตระกูล AirPods เป็นแบบ best-effort ผ่าน API สาธารณะ

## การคอมไพล์จากซอร์สโค้ด

เปิด `DuoBar.xcodeproj` ใน Xcode เลือกสคีม **DuoBar** แล้วรัน บิลด์แบบ Debug จะมีเครื่องมือจำลองสถานะและเครื่องมือสำหรับถ่ายภาพการตลาดรวมอยู่ด้วย โดยเครื่องมือเหล่านี้จะถูกตัดออกจากบิลด์ Release

## ข้อจำกัดความรับผิดชอบ

DuoBar เป็นโปรเจกต์อิสระ ไม่มีความเกี่ยวข้องหรือได้รับการรับรองจาก Apple Inc.
